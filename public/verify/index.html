Verify it yourself

Every set of lines is saved as a file the moment we publish it. Three things make sure nobody, us included, can change it afterwards.

1. The file is public. Each match page links to its file on GitHub. Every change to the repository is recorded with its time, in public.

2. Its fingerprint is posted on X. When the file goes out we post its SHA-256 fingerprint on @OddsorEven. Change one digit in the file and the fingerprint comes out completely different. Download the file and check: on Windows, certutil -hashfile file.json SHA256; on Mac or Linux, shasum -a 256 file.json. The result must match the post and the list in data/ledger.csv.

3. It is anchored in Bitcoin. Next to each file sits a .ots proof from OpenTimestamps. Drop both on opentimestamps.org and it shows the time the file existed, confirmed by the Bitcoin blockchain within hours.

News updates (injuries, team news) go out as new files with their own time and reason. They never overwrite the original line.
