Verificalo tu

Ogni gruppo di linee viene salvato in un file nel momento in cui lo pubblichiamo. Tre cose garantiscono che nessuno, noi compresi, possa cambiarlo dopo.

1. Il file è pubblico. Ogni pagina partita rimanda al suo file su GitHub. Ogni modifica al repository è registrata con il suo orario, in pubblico.

2. La sua impronta è pubblicata su X. Quando il file esce pubblichiamo la sua impronta SHA-256 su @OddsorEven. Basta cambiare una cifra nel file e l'impronta cambia completamente. Scarica il file e controlla: su Windows certutil -hashfile file.json SHA256; su Mac o Linux shasum -a 256 file.json. Il risultato deve coincidere con il post e con l'elenco in data/ledger.csv.

3. È ancorato a Bitcoin. Accanto a ogni file c'è una prova .ots di OpenTimestamps. Carica entrambi su opentimestamps.org: mostra l'orario in cui il file esisteva, confermato dalla blockchain di Bitcoin entro poche ore.

Gli aggiornamenti (infortuni, notizie di squadra) escono come nuovi file con il loro orario e il motivo. Non sovrascrivono mai la linea originale.
